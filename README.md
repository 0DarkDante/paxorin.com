# Paxorin — шиномонтаж у Києві

Сайт автосервісу з описом послуг, орієнтовними цінами та формою запису. Допомагає обрати послугу, розрахувати її вартість і підготувати заявку безпосередньо в браузері.

**[Відкрити сайт →](https://0darkdante.github.io/paxorin.com/)**

![Шиномонтаж Paxorin](assets/images/hero.jpg)

## Можливості

- **Послуги та ціни:** заміна шин, балансування, ремонт проколів і сезонне зберігання.
- **Калькулятор вартості:** враховує послугу, діаметр і кількість коліс, RunFlat та SUV.
- **Форма запису:** перевіряє ім’я, український номер телефону та згоду на обробку даних.
- **Зручна навігація:** мобільне меню, плавний перехід до розділів і підсвічування поточного розділу.
- **Відповіді на запитання:** інтерактивний блок FAQ.
- **Контакти:** карта проїзду, телефон, електронна пошта та індикатор робочого часу.
- **Приватність:** окремі сторінки політики конфіденційності й cookies; вибір користувача зберігається в `localStorage`.

## Технології

**HTML5 · CSS3 · JavaScript · GitHub Pages**

Статичний сайт без npm-залежностей і кроку збірки. Усі сторінки мають розширення `.html` та можуть публікуватися на GitHub Pages.

## Структура проєкту

```text
paxorin.com/
├── index.html          # Головна сторінка
├── privacy.html        # Політика конфіденційності
├── cookies.html        # Правила використання cookies
├── assets/
│   ├── styles.css      # Стилі сайту
│   ├── script.js       # Навігація, калькулятор, форма та інтерактивні елементи
│   └── images/         # Зображення та логотип
├── robots.txt          # Правила для пошукових роботів
├── sitemap.xml         # Карта сайту
└── .nojekyll           # Публікація статичних файлів без обробки Jekyll
```

## Локальний запуск

1. Клонуйте репозиторій:

   ```bash
   git clone https://github.com/0DarkDante/paxorin.com.git
   cd paxorin.com
   ```

2. Відкрийте `index.html` через **Live Server** у VS Code. Або, якщо встановлено Python 3, запустіть:

   ```bash
   python3 -m http.server 8000
   ```

   Відкрийте [localhost:8000](http://localhost:8000).

## Як працює запис

Після перевірки полів форма готує лист і відкриває поштовий клієнт через `mailto:`. Користувач має самостійно надіслати цей лист. Скрипт також намагається скопіювати текст заявки в буфер обміну, якщо браузер це дозволяє.

Серверної обробки заявок немає. Значення калькулятора є орієнтовними; індикатор робочого часу використовує локальний час пристрою.

## Публікація

GitHub Pages публікує сайт із **кореня гілки `main`**. Після завантаження змін GitHub автоматично оновлює живу сторінку.

```bash
git add .
git commit -m "Update website"
git push
```

Адреса публікації: **https://0darkdante.github.io/paxorin.com/**

SEO-посилання в HTML, `robots.txt` і `sitemap.xml` наразі вказують на домен `paxorin.com`. Вони не означають, що цей домен підключений до GitHub Pages.
